# Aksharam — The Living Library

A responsive Next.js author website concept for a Hindi and Sanskrit writer.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Replace the demo content
Edit `app/page.tsx`:
- Replace `[Author's Name]` and the author biography.
- Update the `books` array with real titles, descriptions, languages, years, ISBNs, publisher and copyright details.
- Replace `hello@aksharam.example` with the real contact email and social links.

Book details, author identity, and contact details in this demo are placeholders. The cover artwork is CSS-based concept art, not actual published book covers.
